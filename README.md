# MTB_Mut_Clust

## Usage

`jupyter notebook` code for analyses found in the `scripts` subdirectory. Input and output data found in the `data` subdirectory. 

## Environment requirements
see `environment.yml` file 

## Citation
>[*The structural context of mutations in proteins predicts their effect on antibiotic resistance*](https://doi.org/10.1101/2025.09.23.676583) \
>Anna G. Green, Mahbuba Tasmin, Roger Vargas Jr, Maha R. Farhat\
>eLife 2025;14:RP109450 DOI: https://doi.org/10.7554/eLife.10945

Code to generate the structure database is found [here](https://github.com/aggreen/EVcouplings/tree/feature/structure_finder) and is a fork from the [EVcouplings repository](https://github.com/debbiemarkslab/EVcouplings). 

This study uses ancestral sequence reconstruction data originally published in [Vargas _et al._, PNAS, 2023.](https://doi.org/10.1073/pnas.2301394120)
